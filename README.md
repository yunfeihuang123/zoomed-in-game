**Can you identify the object in the zoomed in photo?**

This game is designed for remote teams as an ice breaker or fun way to engage geographically dispersed teams.
The idea is to supply images and the app will zoom on part of the picture to obfuscate the entire image.
Participants will then have to guess what the object is based on the zoomed in picture.

This app runs natively using any browser without being blocked if using a publicly hosted platform at work.
